### **NutriAI User Guide**



#### 1\. Account Creation



Users create an account and define their dietary preferences

including allergies, diet type and health goals in profile page.



#### 2\. Searching Recipes



Users can search recipes using keywords or ingredients.



#### 3\. Viewing Recipes



Opening a recipe records a "view" interaction.



#### 4\. Saving Recipes



Users can save recipes they want to cook later.



#### 5\. Cooking Recipes



When the user click recipe is cooked, the system records a strong behavioral signal

which increases the likelihood of similar recipes being recommended.



#### 6\. Recommendation Behavior



NutriAI updates recommendations based on user interactions.



Interaction weights:



View = exploratory signal

Save = intent signal

Cook = confirmed preference
